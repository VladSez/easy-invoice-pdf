# How EasyInvoicePDF works

> Canonical page: https://easyinvoicepdf.com/how-it-works  
> Invoice editor: https://easyinvoicepdf.com/
> Language: English  
> Last updated: 2026-08-02

EasyInvoicePDF lets users create a professional PDF invoice in the browser: enter seller and buyer information, add invoice items and tax settings, customize the document, review the live preview, and download the PDF. No account or sign-up is required.

## Basic workflow

1. Open the invoice editor.
2. Add or select seller details.
3. Add or select buyer details.
4. Enter the invoice number, dates, currency, language, and line items.
5. Configure discounts, VAT, GST, sales tax, or custom tax labels if required.
6. Choose a template and optionally add a logo or QR code.
7. Check the live PDF preview and totals.
8. Download the PDF or create a shareable link for a trusted recipient.

## Data handling

Normal editing, preview, and PDF generation run in the browser. EasyInvoicePDF does not store invoice content on its servers during the normal edit-and-download workflow. A shareable invoice URL contains a compressed copy of the invoice data and should be treated as sensitive.
